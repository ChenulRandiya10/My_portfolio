# Vercel Setup

This project deploys as a static Vite app.

## Settings

- Root Directory: project root
- Build Command: `npm run build`
- Output Directory: `client/dist`
- Install Command: `npm install`

No API environment variables are required.

## Contact Form

The contact form uses FormSubmit to email submissions to `chenulrandiya10@gmail.com`. Confirm the first FormSubmit email from that inbox so future messages are delivered.
