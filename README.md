# My Portfolio

Personal portfolio website built with React and Vite.

## What this includes

- React landing page with hero, about, work experience, education, projects, skills, and contact sections
- Contact form that sends submissions to `chenulrandiya10@gmail.com` through FormSubmit
- Client-only Vite app with no backend server or message dashboard

## Setup

1. Install dependencies with `npm install` from the project root.
2. Start the app with `npm run dev`.
3. Build for production with `npm run build`.

## Contact Form

The first FormSubmit submission to `chenulrandiya10@gmail.com` may send a confirmation email. Confirm it once, then future contact form submissions will arrive in that inbox.
